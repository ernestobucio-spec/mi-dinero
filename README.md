# Mi Dinero Pro

App personal de control de dinero (cuentas, gastos, presupuestos, metas y deudas) que corre igual en iPhone (app web instalable) y en Mac (Electron), con sincronización entre dispositivos.

- Instalar en iPhone: abrir https://ernestobucio-spec.github.io/mi-dinero/ en Safari → Compartir → Añadir a pantalla de inicio.
- Los datos viven en el dispositivo y, si se vincula, en un proyecto propio de Supabase protegido con una clave de sincronización.
- Sin frameworks: HTML, CSS y JavaScript. Librerías incluidas: qrcode-generator (MIT) y jsQR (Apache-2.0).
